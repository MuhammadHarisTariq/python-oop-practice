# 🐍 Python OOP Practice

A collection of Python programs and exercises created to practice and understand **Object-Oriented Programming (OOP)** concepts in Python.

## 📚 Topics Covered

* Classes & Objects
* Constructors (`__init__`)
* Instance Variables & Methods
* Class Variables & Methods
* Static Methods
* Encapsulation
* Abstraction
* Inheritance
* Polymorphism
* Method Overriding
* Special / Magic Methods
* Operator Overloading

## 🎯 Purpose

The purpose of this repository is to strengthen my understanding of Python OOP concepts through **hands-on coding, examples, and practice problems**.

## 🛠️ Technologies

* **Python 3**
* **VS Code**
* **Git & GitHub**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/python-oop-practice.git
```

Navigate to the project:

```bash
cd python-oop-practice
```

Run any Python file:

```bash
python filename.py
```
